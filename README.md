# CinemaBookingApp

Кино, тоглолтын жагсаалтаас суудлаа сонгож тасалбар захиалах программ.

Java 17, JavaFX 21, Maven, MySQL ашигласан.

## Боломжууд

- Хэрэглэгч бүртгүүлэх, нэвтрэх
- Кино болон тоглолтын жагсаалт харах
- Суудал сонгож захиалах, захиалгаа цуцлах
- Өмнөх захиалгуудаа харах
- Админ кино, тоглолт болон танхимын мэдээлэл засах, захиалга хайх
- Танхим нэмэхэд суудлууд нь мөр, баганын тоогоор үүсэх

## Шаардлагатай зүйлс

- JDK 17 ба түүнээс дээш хувилбар
- Maven 3.8 ба түүнээс дээш хувилбар
- MySQL Server 8.x
- SceneBuilder (FXML дэлгэцүүдийг визуалаар засах бол)

## Өгөгдлийн сан тохируулах

MySQL серверээ асаагаад тохиргооны жишээ файлыг хуулна:

```bash
cp src/main/resources/db.properties.example src/main/resources/db.properties
```

`src/main/resources/db.properties` файлын `db.user` болон `db.password` утгыг өөрийн MySQL тохиргоонд тааруулна. Энэ файл локал тохиргоонд зориулагдсан тул Git-д нэмэхгүй.

`db.url` дахь `createDatabaseIfNotExist=true` тохиргоогоор `cinema_booking` сан үүснэ. Апп анх нээгдэхэд шаардлагатай хүснэгтүүдийг мөн үүсгэж, `admin` хэрэглэгч байхгүй бол нэмнэ.

Шинээр үүссэн админы нэвтрэх мэдээлэл:

- Нэр: `admin`
- Нууц үг: `admin123`

## Ажиллуулах

Төслийн үндсэн хавтаснаас:

```bash
mvn clean javafx:run
```

## Ашиглах нь

Бүртгэл үүсгээд нэвтэрсний дараа жагсаалтаас кино эсвэл тоглолтоо сонгоно. Сул суудлаа сонгон захиалж, захиалгын түүхээсээ цуцалж болно.

Админ эрхээр нэвтэрвэл кино, тоглолт болон танхимын мэдээллийг удирдаж, бүх захиалгыг хайж, бүртгэлтэй хэрэглэгчдийг харах боломжтой.

## Нууц үгийн хадгалалт

Нууц үгийг тодоор хадгалдаггүй, санамсаргүй `salt`-тай SHA-256 hash хадгалдаг.
